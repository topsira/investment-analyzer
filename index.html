Apps Script Integration Guide

To sync your data with Google Sheets, deploy a Google Apps Script in your spreadsheet. 

// Google Apps Script Setup
function doGet(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  if (!isAuthorized(e)) return createJson("Unauthorized", 401);
  var transactions = readSheet(ss.getSheetByName("Transactions"));
  return createJson({ status: "success", transactions: transactions }, 200);
}

function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  if (!isAuthorized(e, data.accessKey)) return createJson("Unauthorized", 401);
  if (data.action === "saveTransactions") {
    writeTransactions(data.transactions);
    return createJson({ status: "success" }, 200);
  }
}

Create a spreadsheet with sheet named Transactions (columns: id, date, type, symbol, quantity, pricePerUnit, totalValue, notes, createdAt) and sheet Config with ACCESS_KEY row.
